Panel de la bitácora

Conecta tu cuenta de GitHub

Este panel escribe directo en el repositorio pahlass/status — sin servidor propio, sin base de datos. Necesita un token de acceso personal con permiso de escritura solo sobre ese repositorio.

  1. Ve a github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → pahlass/status
  3. Permissions → Repository permissions → Contents → Read and write
  4. Generate token, y pégalo aquí abajo
Token de acceso

El token se guarda solo en este navegador (localStorage) — nunca se envía a ningún lado más que a GitHub.
